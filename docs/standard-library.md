# Jaguar Standard Library API

- `live.on(val)`: Output value or string
- `live.in()`: Read input string
- `live.log(msg)`: Output development diagnostic
- `live.deg(type, expected, variable)`: Static 3-argument debug assertion
- `File.open(path, mode)`: Open file
- `File.read(file)`: Read full file contents
- `File.close(file)`: Close file handle
- `dir.on(path)`: Open directory
- `dir.read(dir)`: Read entries
- `dir.close(dir)`: Close directory handle
